# Amazon Clone

A responsive e-commerce frontend inspired by Amazon, built to practice modern web design and frontend development.

## Features

- Responsive and clean user interface
- Navigation bar and search interface
- Product categories and product cards
- Hero section with promotional content
- Structured and reusable CSS styling

## Tech Stack

HTML5 • CSS3

## Purpose

Built as a frontend development project to strengthen HTML and CSS skills through a real-world e-commerce interface.
